# 材料の大きさ・個数の目安

確認日: 2026-10-18。実装は `src/measures.mjs`、検証は `tests/measures.test.mjs`。

材料の g を変えず、横に個数・枚数・計量スプーンの概算を添える。人数変更後と買物リストの集計後も、表示対象の g から計算する。野菜の大きさ、肉の厚み、商品の容量には差があるため、調理に使う量は g を優先する。

味の素の重量表は廃棄部分を含む一般的な大きさの目安で、可食部だけの厳密な換算表ではない。皮・根・芯などを除いた後の重さと同一とは扱わない。分数を丸める処理も含め、はかりの代わりではなく、材料を選ぶときのサイズ感を補う表示とする。1玉・1丁・1パックなどの基準重量は目安の横に表示する。

## 公開一次資料と採用値

以下は、説明文や写真を転載せず、公開された重量の事実を当サイトの用途に整理したもの。

[古賀市「食材・調味料の量・重さ」](https://www.city.koga.fukuoka.jp/recipe/seasoning/)から、ご飯は茶碗1杯150g、鶏むね肉は1枚250g、ウインナーは1本17g、バジルは2枚1gの目安を採用。鶏むね肉などは資料間でもサイズ差があるため、必ず「1枚250gの場合」のように条件を表示する。

もやしは、[キッコーマンの商品発表にある材料例](https://www.kikkoman.com/jp/news/2025/25028.html)の1袋200gを採用し、「200g入りの場合」と表示する。一般のもやしがすべて200g入りであるとは扱わない。

ごぼうは、少量のときは[宝塚市・宝塚栄養士会のレシピ](https://www.city.takarazuka.hyogo.jp/1060682/1060702/1061588/1017522/1017744/1017750/1036416.html)の20g約10cmを採用する。150g以上の集計では味の素の1本150gに切り替える。長さの基準は太さによって変わるため概算に限る。

### 市販麺

ゆでうどんは[シマダヤ「真打 もちもちうどん 1食」](https://www.shimadaya.co.jp/products/category/chilled/udon/006394/)の200g、蒸し焼きそば麺は[東洋水産「マルちゃん焼そば 3人前」](https://www.maruchan.co.jp/products/search/maruchanyakisoba_3ninmae.html)の1食分150gを、容量の一例として使う。いずれも「1玉200gの場合」などと表示し、銘柄指定や推薦はしない。生麺・乾麺にはこの換算を適用しない。

### 調味料

根拠は[古賀市の重量表](https://www.city.koga.fukuoka.jp/recipe/seasoning/)。小さじは5ml、大さじは15mlで、下表はすり切り小さじ1杯の重さ。大さじは3倍の重量として扱う。

| 材料 | 小さじ1杯 |
| --- | --- |
| 砂糖（上白糖） | 3g |
| 塩（食塩） / みそ | 6g |
| バター / マヨネーズ / ベーキングパウダー | 4g |
| 粉チーズ / カレー粉 | 2g |
| 白いりごま / 薄力粉 / 片栗粉 | 3g |
| ケチャップ | 5g |
| 乾燥パン粉 | 1g |

砂糖は上白糖、塩は食塩という条件を表示する。グラニュー糖・粗塩等が注記された場合には、この密度を流用しない。小さじ1/8未満の微量にはスプーンの目安を出さない。顆粒だし・鶏がらスープなど商品差が大きい調味料も対象外とし、既存の製品表示優先の注記を維持する。

## 換算と例外

- 分数は読みやすい候補から最も近いものを採用する。1未満では相対差が15%を超える候補しかない場合は表示しない。1以上10未満では1/4刻み、10以上では整数に丸める。元の g は丸めない。
- 大根は0.5cm単位、ごぼうは1cm単位の概算にする。太さによる差がある。
- ロールキャベツのように材料注記に「包める」「肉だね」がある場合は、分数枚を案内せず、肉だねの数に合わせて大きな葉を用意する案内を優先する。買物集計の `notes` 配列でも同じ判定にする。
- 水切り後のツナ・サバ缶・コーン等を、汁込みの缶容量に換算しない。豚こま・ひき肉・むきエビなどの不定形の肉魚にも、根拠のないパック数や尾数を足さない。
- 数量未定、0以下、非有限の値、g以外の単位、対応していない状態の食材には表示しない。
- 個数表示は「必要な使用量」のイメージであり、整数単位へ切り上げた購入個数ではない。買物チェックの判定・必要量計算には従来どおり g を使う。

この変更で材料・調理工程の分量自体や、60品が未試作であることは変わらない。
