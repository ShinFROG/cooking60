# 初心者向けの基本セット

確認・集計日：2026年10月18日

掲載先は `src/guide.html` の `#pantry-basics`。このサイトの60品を始めるための買物候補を、材料の使用頻度と日常的な使い道から独自に選んだ。全品を先に買うことや、大量に常備することは求めない。次の3日程度の献立で必要になるものから、小容量で足していく。

## 使用頻度の根拠

対象は `data/public/recipes-lunch.json` と `data/public/recipes-dinner.json` の計60件。材料の `name` が一致する料理の件数を集計した。同一料理内に同名材料が複数あっても1件とし、使用量や献立上の登場回数は件数に含めない。朝食、利用者の献立変更、追加の買物も含まない。

| 最初の候補 | 使用する料理数 | 選んだ理由 |
| --- | ---: | --- |
| しょうゆ | 35 | 炒め物、丼、煮物に共通して使う |
| サラダ油 | 34 | 加熱調理の基本として使う |
| 塩 | 23 | 下味、味の調整に使う |
| 砂糖 | 22 | 煮物、照り焼き、たれに使う |
| こしょう | 18 | 肉・魚の下味、仕上げに使う |
| ケチャップ | 12 | オムライス、ナポリタンなどに使う |
| 酒 | 12 | 下味、蒸し物、煮物に使う |
| 片栗粉 | 11 | とろみ付け、衣に使う |
| みりん | 10 | 照り焼き、煮物に使う |
| ごま油 | 10 | 炒め物、香り付けに使う |
| みそ | 5 | 基本的な和食の味付けとして使う |
| 酢 | 5 | 甘酢あん、南蛮漬け、たれに使う |

最初の10品は水を除く「調味料」区分の使用頻度が上位のもの。みそ・酢は使用頻度の単純な上位順ではなく、和食の基本の味付けをそろえるために追加した。この12品だけで全60品を調理できるという意味ではない。

| 作る料理に合わせて追加する候補 | 使用する料理数 |
| --- | ---: |
| 薄力粉 | 8 |
| バター | 8 |
| カットトマト缶 | 7 |
| 和風顆粒だし | 6 |
| 洋風顆粒スープの素 | 6 |
| オリーブ油 | 6 |
| 鶏がらスープの素 | 4 |

ご飯（炊飯済み）は39品、米（生）は4品に登場する。両者の重量はそのまま足し合わせたり、生米の購入量として読み替えたりしない。卵、玉ねぎ、にんじん、キャベツは複数の献立で使うが、生鮮食品を一か月分まとめ買いする前提にはしない。

集計の再現例（リポジトリ内で実行）：

```js
import fs from 'node:fs';
const recipes = ['lunch', 'dinner'].flatMap(period =>
  JSON.parse(fs.readFileSync(`data/public/recipes-${period}.json`, 'utf8'))
);
const counts = new Map();
for (const recipe of recipes) {
  for (const name of new Set(recipe.ingredients.map(ingredient => ingredient.name))) {
    counts.set(name, (counts.get(name) ?? 0) + 1);
  }
}
console.log([...counts].sort((a, b) => b[1] - a[1]));
```

## 公開一次情報との照合

- [消費者庁：家庭での食品ロスを減らそう](https://www.no-foodloss.caa.go.jp/eating-home.html)。買物前の在庫確認、利用予定に合わせた必要量の購入、食品の期限表示を確認した。サイトでは「次の3日で使う分を確認」「期限に応じて購入日を分ける」と独自に整理した。3日間保存できることを保証する記述にはしていない。
- [消費者庁：食品表示基準Q&A・期限表示（PDF）](https://www.caa.go.jp/policies/policy/food_labeling/food_labeling_act/assets/food_labeling_cms201_250328_1032.pdf)。最終ページの「期限（消）-7」「期限（消）-8」で、期限表示は未開封かつ指定の保存方法が前提であること、開封後は保存方法が変わる商品もあることを確認した。保存は商品ラベルに従い、開封後は早めに使い切る旨を掲載した。一律の保存日数は指定していない。
- [キッコーマン：2倍・3倍のめんつゆとは何が違うの？](https://www.kikkoman.co.jp/homecook/tsushin/0085/)。濃縮2倍・3倍・4倍で、つけつゆにする際のつゆと水の割合が異なることを確認した。掲載レシピの指定倍率を確認するよう案内し、倍率の違う製品や顆粒だしを同量置換する案内はしない。特定製品を購入する推奨にはしていない。

参照先の本文・商品画像は転載していない。献立への適用と基本セットの選定は本サイトによる編集判断であり、各機関・メーカーによる推奨セットではない。

## 使い方・器具

買物リストの「まだ買うものだけ」は、購入済み、家にある材料、追加の買物のチェック済みを表示上隠す。チェック自体を消さず、「すべて」で確認・変更できる。「家にある」は容器を持っているだけでなく、今回の必要量が残っているかを確かめて使う。

既存の基本器具の説明を引き継ぎ、ざる、菜箸またはへら、計量カップを追加した。道具は手持ちを確認し、個々の料理の道具欄に従って用意する。特定メーカーや価格を指定せず、全員に同じ購入数量を求めない。

## 確認範囲

使用頻度は公開データの実集計、食品の保存・表示・濃縮つゆは公開一次情報との照合。実物の購入、全商品の比較、料理の試作、調理時間計測は行っていない。既存の全60品未試作という表示は維持する。
